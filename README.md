# Praxis

Execution, automated.

Praxis is an autonomous product execution platform. It will eventually coordinate specialized AI agents that plan, design, build, test, and prepare software for delivery.

Current status: Phase 0 — repository foundation and documentation. No AI agents or application features have been implemented yet.

Primary concept: "Execution" — a unit of work that progresses through:

Idea → Planning → Architecture → Build → Testing → Review → Delivery

This repository contains the foundational structure, documentation, and guidelines to begin building Praxis.
