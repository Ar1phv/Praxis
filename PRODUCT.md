# PRODUCT

Praxis — Execution, automated.

Problem:
Turning an idea into production-ready software requires coordination across product, design, and engineering.

Target users:
Founders, solo developers, and small engineering teams who want to accelerate prototyping and reduce friction.

MVP (Phase 0):
Repository and architecture foundation. No agents implemented.

MVP Agents (future):
- Orchestrator
- Product Agent
- Builder Agent

Non-goals for Phase 0:
- Implementing AI agents
- Building production features
